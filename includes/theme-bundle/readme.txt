== Description ==

Hello Olobuild è un tema WordPress leggero e minimale, progettato per funzionare
perfettamente con il page builder Olobuild.

A differenza dei temi standard che impongono stili CSS aggressivi (font-size,
max-width, colori), Hello Olobuild è quasi vuoto — lascia che Olobuild gestisca
tutto il design visuale.

Caratteristiche:
- Zero CSS invasivo — nessun conflitto con il page builder
- Block theme (Full Site Editing) — compatibile con l'editor a blocchi
- Template parts header/footer vuoti — Olobuild li sostituisce automaticamente
- Rimuove stili globali di WP che interferiscono
- Supporta sticky footer, logo personalizzato, menu
- Solo ~3KB di CSS totale

== Installation ==

1. Carica la cartella `hello-olobuild` in `/wp-content/themes/`
2. Attiva il tema da Aspetto > Temi
3. Installa e attiva Olobuild
4. Importa un tema Olobuild (es. "Business Pro") dalla toolbar del builder
