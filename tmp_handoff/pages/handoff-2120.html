Quello che lo rende diverso

Dieci feature di serie, senza plugin esterni

In altri builder le paghi a parte, le configuri con sei plugin, o non ci sono proprio.

  • Border-radius animato hover — quattro angoli indipendenti su tutti i 187 tile. La nostra feature bandiera.
  • Mouse Tilt 3D + cursor tracking — l'elemento ruota seguendo il cursore.
  • Parallax scroll-linked multi-property — opacity, scale, rotate, translate, blur su un singolo elemento mentre scrolli.
  • Visibilità condizionale AND/OR — 24 condizioni componibili (utente loggato, ora del giorno, URL parameter, mobile, ecc.).
  • Text effects su ogni campo — 11 effetti (typewriter, gradient animato, glitch, wave, scramble, reveal letter, highlight grow…) applicabili su qualunque testo.
  • Stagger figli — animazioni propagate ai figli con delay incrementale.
  • Inline editing live — doppio click in canvas, floating toolbar Tiptap, salvi e sei in produzione.
  • Ricerca media multi-provider — Unsplash, Pexels, Pixabay, Openverse, Freesound, Polyhaven HDRI, Google Street View. Tutto nel pannello.
  • Form builder integrato — multi-step, formule, signature, file upload, anti-spam.
  • Olo-Space — 10 tile dedicati a coworking, affittacamere, spazi condivisi.

Sotto al cofano

Codice serio per chi vuole capire

  • Backend — PHP 7.4+, REST API namespace olo/v1, due tabelle dedicate (niente abuso di postmeta).
  • Frontend builder — Vue 3 (Composition API), Pinia, Vite 5, Tailwind con prefix mb-, SASS, UIkit.
  • Drag & drop — basato su @atlaskit/pragmatic-drag-and-drop (performance > vuedraggable).
  • Inline editor — Tiptap con floating toolbar rich text.
  • Auto-discovery tile — ogni tile è 2 file (PHP + config JSON), il registry li importa automaticamente.
  • Codice aperto, niente black box — stessa licenza di WordPress (GPL v3). Niente offuscamento, niente API call obbligatorie a server esterni, niente formato proprietario. Lo modifichi e lo porti dove vuoi.

FAQ OLObuild

Le domande che ci fanno prima di provare

Funziona con il mio tema attuale?

Sì. OLObuild è theme-agnostic: gira su qualunque tema WordPress (classici e block themes). Lo abbiamo testato in particolare con Twenty Twenty-Four, Astra, GeneratePress, Kadence. Distribuiamo gratis anche il nostro tema starter hello-olobuild ottimizzato.

Posso usare OLObuild Free su più siti?

Sì, su un numero illimitato di siti. Codice aperto sotto la stessa licenza di WordPress (GPL v3), niente attivazione tramite key, niente conteggio installazioni.

Quanto incide sulle performance?

Il rendering è server-side PHP (non React/Vue runtime sul frontend). CSS generato per-template, niente bundle JS gigante. Compatible con WP Rocket, LiteSpeed Cache, Cloudflare. Score Lighthouse mobile tipico: 85-95 con immagini ottimizzate.

Come funziona la migration da Elementor / Divi / Bricks?

Tool di migration automatica sono in roadmap (non al lancio). Per ora la migration è manuale via builder: chi conosce Elementor è operativo in 1 giorno con OLObuild (interfaccia simile, terminologia comune).

WooCommerce è supportato?

Sì. OLObuild include automaticamente 31 tile WooCommerce quando WC è attivo: loop prodotti, mini cart, product page, filtri AJAX, badges, checkout custom.

I miei contenuti sono portabili?

Sì. I template sono in JSON ispezionabile in 2 tabelle DB (wp_olo_templates, wp_olo_revisions). Esportabili come file, importabili in altri siti. Niente lock-in.

Posso estenderlo con tile custom?

Sì. Ogni tile è 2 file (PHP class + JSON config). Hook documentati per registrazione tile esterni, auto-discovery via import.meta.glob. Il Technical Paper spiega tutto.

OLObuild Pro vale i € 29?

Le 22 tile Pro da sole equivalgono a un add-on di Elementor (es. JetEngine, Ultimate Addons) che costa € 39-69/anno. Inoltre Pro include OLOlang a vita (valore € 49/anno). Quindi: € 29 di lancio = ~€ 100 di valore equivalente nel mondo Elementor.
