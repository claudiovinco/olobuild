Quello che condividono

Un core, nove componenti, sei verticali

Quando aggiungi un secondo verticale (es. da Hotel a Ristorante annesso), lo configuri — non lo reinstalli da zero.

  • Map + Calendar core — 4 componenti base, 13 wrapper specializzati. Calendari sincronizzati tra verticali.
  • Payment tracking — Stripe + bonifico + acconti. Multi-currency, no fee per transazione (paghi solo Stripe).
  • Multilingua via OLOlang — manager e frontend tradotti, descriptor verticali in IT/EN/DE.
  • Email branded — template configurabili, dominio sender personalizzato, niente "via mailgun.com" nei messaggi.
  • Licensing Ed25519 — server-side, no API call obbligatorie al runtime. Funziona offline.
  • REST API custom — namespace dedicato, ogni endpoint documentato, integrabile con qualunque CRM/PMS esterno.
  • Setup wizard a 5 step — configurazione iniziale in mezz'ora.
  • Integrazione OLObuild — tile + shortcode per ogni verticale, design coerente col tuo sito.
  • Bundle features atomici — JS + CSS sempre allineati, niente "ho aggiornato e si è rotto qualcosa".

FAQ hub OLObooking

Domande sul prodotto-eroe

Devo per forza usare tutti i 6 verticali?

No. Attivi solo i verticali che ti servono. Aggiungi gli altri in qualunque momento — non c'è migration, sono già installati e dormienti.

Quanto costa OLObooking?

Il pricing finale è in finalizzazione (annuncio al lancio Q3 2026). Quello che è certo: licenza annuale per verticale, bundle Suite Agency per chi prende tutti e 6, niente fee per prenotazione, niente cap di volume.

Come si paga sul vostro sistema?

Configuri Stripe (carte) e/o bonifico bancario direttamente sul tuo WordPress. Le commissioni le paghi a Stripe (~1.5% in UE), noi 0%. Acconti, depositi cauzionali, pagamenti rateali, multi-currency: tutto incluso.

Si integra con il mio PMS / CRM esistente?

REST API documentata per ogni verticale. Già pronti integrazioni native: iCal bidirezionale con Airbnb/Booking/VRBO (Accommodation), Google Calendar sync (Appointments). Per CRM esterni: webhook + REST.

I miei dati sono al sicuro?

Sono sul tuo WordPress, sul tuo hosting. OLObooking non li manda a un cloud esterno — niente "OLO Cloud", niente "telemetria obbligatoria". GDPR ready by design.

Funziona con WooCommerce?

Sì. Puoi vendere prodotti WooCommerce e gestire prenotazioni OLObooking sullo stesso sito, con stesso checkout (Stripe condiviso). Per scenari "shop + booking" è ideale.
