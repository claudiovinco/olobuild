FAQ OLOlang

Le domande che ci fanno prima di provare

Quante lingue supporta davvero?

28 lingue native: italiano, inglese, tedesco, francese, spagnolo, portoghese (PT/BR), olandese, polacco, ceco, slovacco, ungherese, rumeno, bulgaro, greco, russo, ucraino, turco, arabo, hebraico, giapponese, cinese (zh-CN/zh-TW), coreano, indonesiano, vietnamita, svedese, danese, norvegese, finlandese. Aggiungi qualunque locale custom via WP-CLI.

Devo avere un account DeepL?

Sì, serve un account DeepL Pro (gratuito per i primi 500k caratteri/mese). Inserisci la tua API key una sola volta nelle impostazioni — le traduzioni passano direttamente dal tuo account DeepL, niente intermediari, niente costi nascosti su OLOlang.

Posso migrare da WPML / Polylang?

Sì. Tool di import automatico per WPML e Polylang al lancio. Le traduzioni esistenti vengono caricate nella translation memory di OLOlang — niente lavoro da rifare. Demo di migration live disponibile su richiesta.

L'SEO funziona per ogni lingua?

Sì. URL strutturati (/it/, /en/ o sottodominio), hreflang automatico, meta title/description per ogni lingua, sitemap.xml multilingua. Compatibile con Yoast, Rank Math, AIOSEO.

WooCommerce è supportato?

Sì: prodotti, varianti, categorie, attributi, recensioni, checkout, email ordine. Multi-currency è in roadmap (oggi devi abbinarlo a un plugin di terze parti). Per ora il supporto WooCommerce è "buono" (vs WPML "eccellente con multi-currency").

I dati dove finiscono?

Sul tuo WordPress, sempre. Tabelle dedicate sul tuo database (wp_olo_lang_strings, wp_olo_lang_memory). DeepL processa i testi e li restituisce a OLOlang — DeepL non li archivia (è esplicito nei loro Termini Pro).

Posso disattivarlo senza perdere le traduzioni?

Sì. Le traduzioni restano nelle tabelle dedicate. Tool di export in JSON e XLIFF nativo. Niente lock-in.

Cosa succede ad OLOlang dopo il primo anno gratis?

OLOlang resta attivo — le traduzioni continuano a funzionare, il language switcher gira regolarmente. Quello che si interrompe sono solo gli aggiornamenti: niente nuove feature, niente fix di sicurezza nuovi. Niente "site-lock", mai. Per averlo aggiornato a vita, passa a OLObuild Pro a € 29: include OLOlang aggiornato per sempre.
