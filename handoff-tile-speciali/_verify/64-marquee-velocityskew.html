Verifica runtime — Marquee · VelocitySkew

Replica fedele di ciò che Olo_Marquee_Tile::render() stampa con velocity_skew = true. Scorri la pagina su e giù, anche di scatto: i due nastri prendono spinta e si inclinano proporzionalmente alla velocità, poi lo skew si smorza tornando a 0.

  • Multi-istanza / scoping: le due barre hanno UID diversi e parametri diversi (la rossa è più reattiva, va a destra). Non si influenzano.
  • Pausa hover: tieni il mouse fermo su una barra → si ferma il drift (lo skew rientra).
  • reduced-motion: DevTools → Rendering → Emulate CSS prefers-reduced-motion: reduce → ricarica. I nastri tornano al solo drift CSS, skew 0 (nessun JS).
  • Fallback no-JS: DevTools → disabilita JavaScript → ricarica. I nastri scorrono lo stesso (animazione CSS di base).

Lo stato è ispezionabile da console: document.querySelector('.olo-mq-77001 .olo-mq-track').dataset.oloVskew deve valere "1" e ...track.style.animation deve essere "none" quando il JS ha preso il controllo.
