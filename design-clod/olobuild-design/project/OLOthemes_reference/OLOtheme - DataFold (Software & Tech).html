Model once, in plain SQL

Define your metrics as version-controlled models. DataFold compiles them into fast, governed queries — so everyone's numbers come from the same place.

  • Git-backed semantic layer
  • Column-level lineage
  • Tests that block bad data shipping
Read the docs 
-- models/revenue.sql
metric net_revenue as (
  select date_trunc('week', paid_at) as wk,
         sum(amount) - sum(refunds)
  from {{ ref('payments') }}
  group by 1
)
